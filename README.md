# 📊 My SQL Practice Lab

Welcome to my personal repository dedicated entirely to learning and practicing SQL. This repository serves as my hands-on workbook where I write, test, and optimize MySQL scripts.

## 🛠️ Tech Stack & Tools
* **Database Engine:** MySQL
* **GUI Editor:** MySQL Workbench

## 🗂️ What's Inside?
* **DDL Scripts:** Creating databases, defining schemas, and managing tables.
* **DML Practices:** Inserting, updating, and safely deleting records.
* **Query Labs:** Practicing data retrieval using `WHERE` filters, `GROUP BY` aggregations, and multi-table operations.
